誓About This Hub

Japanese Heavy Music Hub is a fan-built portal dedicated to the Japanese female-fronted heavy music scene — from BAND-MAID's disciplined groove to LOVEBITES' NWOBHM fire, NEMOPHILA's technical shred, Hanabie.'s kawaii-core chaos, Unlucky Morpheus's symphonic power, BABYMETAL's genre-defining fusion, DenKare's gothic-metal theatrics, and Yousei Teikoku's symphonic darkness.

Built with plain HTML, CSS and JavaScript — no frameworks — so it stays fast and easy to host on GitHub Pages.
